## Overview

Eye Candy delivers 32 stylized visual effects for motion graphics: glow, bevel, chrome, fire, smoke, lightning, and HSL adjustments, all with real-time GPU-accelerated preview in After Effects and Photoshop.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Eye Candy** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **32 Effects** | Glow, bevel, chrome, fire, smoke, lightning, and 26 more GPU-accelerated |
| **Real-Time Preview** | Hardware-accelerated GPU preview eliminates slow software renders |
| **Text Support** | Effects respect text layer outlines for clean animated typography |
| **Preset Library** | 600+ factory presets organized by category with thumbnail previews |
